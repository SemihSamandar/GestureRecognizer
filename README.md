A UIKit playground project for experimenting with `UIGestureRecognizer` (tap, swipe, pinch, etc.) on iOS.

## 🛠️ Tech

- Swift, UIKit
- Storyboards / Interface Builder

## 🚀 Getting Started

```bash
git clone https://github.com/SemihSamandar/GestureRecognizer.git
cd GestureRecognizer
open GestureRecognizer.xcodeproj
```

Pick a simulator in Xcode and press **⌘R** to run.
